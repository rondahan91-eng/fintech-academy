# FinTech Academy

אפיון לקורס **יסודות התכנות בפייתון + חינוך פיננסי** לכיתה י', מגמת הנדסת אלקטרוניקה ומחשבים.

התלמידים משחקים עובדים זוטרים בחברת פינטק: מקבלים משימות שבועיות ופניות לקוחות, מתקדמים בדרגות, מרוויחים שכר וירטואלי, מפרישים לפנסיה — והפנסיה מתורגמת בסוף השנה לחלק מהציון.

**שתי מטרות במקביל:** ללמד לתכנת בפייתון, וללמד חינוך פיננסי.

## תאימות

תכנית הלימודים "יסודות התכנות בשפת Python", סמל מקצוע **11.004**, גרסה 3 (מרץ 2022), משרד החינוך — המינהל למדע ולטכנולוגיה.

**הפריסה כאן חורגת מהרשמית:** 2 ש"ש (60 שעות) במקום 4, עם תקרת תוכן גבוהה יותר (עד פרק 7 — פונקציות) ובעומק נמוך יותר. פרק 5 (מחרוזות) נדחה כולו לכיתה יא'. הגירעון הדו-שנתי מתועד ב-SPEC.md פרק 10.0 ומחייב אישור.
