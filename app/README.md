# `app/` — פרוסה אנכית, שבוע 1

**לא אב-טיפוס של המערכת. פרוסה אחת מקצה לקצה**, שנבנתה כדי לענות
על שאלה אחת: **האם המספרים ב-`design/layout.md` נכונים כשמריצים אותם.**

## מה רץ כאן

```
content/week-01/  →  tools/build_app_content.py  →  app/content.js  →  app/app.js
```

| | |
|---|---|
| **עורך** | textarea + מספרי שורות + שמירה אוטומטית ל-localStorage |
| **הרצה** | Pyodide בדפדפן. הפלט לטאב "פלט" |
| **בדיקות** | ארבע הבדיקות הגלויות של שבוע 1, עם `OUTPUT` ו-`LINES` |
| **אלעד** | הפריסה מלאה. **הטקסט stub — אין כאן מודל** |
| **גרירה** | הקו נגרר 196–376, נפתח לבדו פעם אחת |
| **מד הפריסה** | הקופסה השחורה בפינה. **כלי פיתוח, לא מוצר** |

## הרצה

```bash
py tools/build_app_content.py 1
```

ואז שרת סטטי על `app/` (הוגדר ב-`.claude/launch.json`, פורט 8123).
**חייב שרת** — `app.js` הוא מודול, ו-`file://` יחסום אותו.
