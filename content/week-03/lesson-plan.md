# חלק א' — פרונטלי (0:00–0:45)

## 1. הבעיה שמשתנים פותרים (0:00–0:10)

**אל תתחיל מהתחביר.** תתחיל מהכאב.

הקרן על הלוח קוד בסגנון שבוע 1:

```python
print("שכר: 12500")
print("אחרי העלאה: 12500")
print("סה\"כ שנתי: 12500")
```

*"הלקוחה קיבלה העלאה. תגידו לי איפה צריך לשנות."*

בשלוש שורות זה מעצבן. תשאל מה יקרה בתוכנית של מאתיים שורות. **זו הסיבה שמשתנים קיימים** — נתון שנשמר במקום אחד ומשתנה במקום אחד.

## 2. משתנה והשמה (0:10–0:20)

```python
salary = 12500
print(salary)
```

שלוש נקודות שכדאי לומר במפורש:

- `=` **אינו "שווה".** הוא "שים בתוך". `salary = 12500` פירושו: קח את 12500 ושים בקופסה ששמה salary.
- **הקופסה נוצרת ברגע ההשמה.** אין הצהרה מראש.
- `print(salary)` מדפיס את **הערך**; `print("salary")` מדפיס את **השם**. הדגם את שניהם זה אחרי זה — הפער ביניהם הוא כל המושג.

### השמה מחדש

```python
salary = 12500
salary = 13750
print(salary)
```

*"מה יודפס?"* — תן להם לנחש לפני שאתה מריץ. הקופסה מחזיקה ערך אחד, האחרון שנכנס.

## 3. ארבעת הטיפוסים (0:20–0:35)

| טיפוס | מה זה | דוגמה |
|---|---|---|
| `int` | מספר שלם | `34` |
| `float` | מספר עשרוני | `12500.5` |
| `str` | טקסט | `"רותם"` |
| `bool` | כן / לא | `True`, `False` |

### `type()`

```python
x = 34
print(type(x))
```

תריץ על כל ארבעת הטיפוסים. שיראו את הפלט האמיתי, כולל `<class 'int'>`.

### שתי מלכודות שכדאי להראות עכשיו

- **`True` באות גדולה.** `true` תיתן שגיאה. הדגם.
- **`"34"` אינו `34`.** אותו תו על המסך, שני טיפוסים שונים. הרץ `type("34")` ו-`type(34)` זה אחרי זה.

## 4. תרגול מודרך — כרטיס ספרייה (0:35–0:45)

שיכתבו במחשב שלהם, בעצמם:

```
book_title   = "..."      (טקסט)
pages        = 320        (מספר שלם)
rating       = 4.5        (עשרוני)
is_borrowed  = False      (בוליאני)
```

ואז: להדפיס את כולם, להדפיס את הטיפוס של כל אחד, ולשנות את `is_borrowed` ל-`True`.

**זו בדיוק המשימה בבנק** — חמישה משתנים, ארבעה טיפוסים, השמה מחדש — על תוכן אחר לגמרי. התלמיד מגיע לבנק עם היכולת ובלי הפתרון.

### מי שסיים מהר

להוסיף `library_card = "0034521"` ולשאול אותם מה קורה אם שומרים אותו בלי גרשיים. **אל תענה** — תגיד שזה בדיוק מה שאלעד ידבר עליו.

# חלק ב' — עבודה בבנק (0:45–1:30 ← גולש לשיעורי בית)

## 5. עבודה על המשימה

מכאן אתה מסתובב.

### מה לחפש

| סימן | מה לעשות |
|---|---|
| שמר את מספר החשבון כמספר | ✅ **הכי טוב שיכול לקרות.** לא לתקן — להפנות לאלעד |
| `print("customer_name")` עם גרשיים | לשאול מה הוא רואה ומה ציפה. לא לתקן ישירות |
| יצר משתנה חדש בחלק ג' | להפנות לאלעד — יש לו סולם רמזים לזה |
| שגיאת כתיב בשם משתנה | להפנות לשגיאה עצמה: "מה כתוב שם?" |
| מנסה לחשב את ההעלאה | לומר שהשבוע רק שומרים. חשבון בשבוע הבא |
| סיים מהר | להוסיף שדה משלו לתיק — עיר מגורים, תאריך פתיחה |

### מתי כן להתערב

תקלות סביבה בלבד. ושגיאת `True`/`true` — זו שגיאת שפה טהורה ושלך.

## 8. הערכה — מה אמור לקרות

**כל תלמיד:** הגדיר משתנה, הדפיס אותו, ושינה את ערכו.

**רוב הכיתה:** יודעים להבחין בין `print(x)` ל-`print("x")`.

**סימן שהשיעור הצליח:** תלמיד שואל **"אז מתי כן שומרים מספר כמספר?"** — זו השאלה שאלעד מחכה לה.

**סימן שצריך לחזור:** תלמיד שמגדיר משתנה בכל פעם שהוא צריך אותו, במקום פעם אחת. הוא רואה בהשמה פקודת הדפסה ולא אחסון.
