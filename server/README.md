# השרת — הקמה מאפס

**עשרים דקות, ואתה עושה את זה בעצמי.** אני לא יכול לפרוס בחשבון Google
שלך ולא להזין את מפתח ה-API — שניהם שלך, ושניהם פעולות שרק אתה מורשה
לעשות.

בסוף התהליך יש לך כתובת אחת. היא נכנסת ל-`app/config.js` וזהו.

---

## 1 · הגיליון

צור גיליון Google חדש בשם **FinTech Academy — כיתה י'**.

**Extensions → Apps Script.** נפתח עורך קוד.

| מה | מאיפה |
|---|---|
| מחק את `Code.gs` הריק והדבק במקומו | `server/Code.gs` |
| הוסף קובץ חדש בשם `Prompt` והדבק | `server/Prompt.gs` |

> `Prompt.gs` נוצר אוטומטית מקבצי התוכן. **אל תערוך אותו ביד:**
> ```bash
> py tools/build_server_prompt.py 1
> ```

שמור. חזור לגיליון ורענן אותו — יופיע תפריט **FinTech**.

**FinTech → הכן את הגיליונות.** נוצרים ארבעה: `roster`, `progress`,
`submissions`, `chat`.

---

## 2 · המפתח

ב-Apps Script: **⚙ Project Settings → Script Properties → Add property**

| Property | Value |
|---|---|
| `ANTHROPIC_API_KEY` | המפתח שלך מ-console.anthropic.com |

> ⚠️ **המפתח נשאר כאן ולעולם לא מגיע לדפדפן.** זו כל הסיבה שיש שרת
> ולא קוד שרץ אצל התלמיד. אל תשים אותו ב-`config.js`, אל תשלח אותו
> בווטסאפ, ואל תעלה אותו לגיט.

חזור לגיליון: **FinTech → בדוק שהמפתח עובד.** אמור לענות "המפתח עובד".

---

## 3 · רשימת הכיתה

בגיליון `roster`, הדבק את שמות התלמידים **בעמודה `name` בלבד**.
השאר את `id` ו-`code` ריקים.

**FinTech → צור קודים לתלמידים חדשים.**

```
id     name        code     class   active
S001   דן כהן      417293   י3      yes
S002   יוסי לוי    806142   י3      yes
```

**הדפס את הגיליון וגזור לפתקים**, או הקרן אותו ותן לכל אחד את הקוד שלו.

> הקוד הוא שש ספרות אקראיות. **זו לא אבטחה** — הוא מונע כניסה בטעות
> בשם חבר, לא כניסה מכוונת. אין כאן ציונים ואין מידע רגיש, ואסור
> שיהיה. הרצה חוזרת של הפקודה **לא** מחליפה קודים קיימים.

---

## 4 · הפריסה

ב-Apps Script: **Deploy → New deployment → ⚙ → Web app**

| שדה | ערך | למה |
|---|---|---|
| Execute as | **Me** | השרת ניגש לגיליון בשמך |
| Who has access | **Anyone** | התלמידים אינם מחוברים ל-Google בשיעור |

לחץ **Deploy**, אשר את ההרשאות, והעתק את **Web app URL**.

> **"Anyone" נשמע מפחיד ואינו מה שנדמה.** אין כאן דף גלוי — יש נקודת
> קצה שכתובתה היא מחרוזת אקראית ארוכה. **הכתובת עצמה היא המפתח**,
> ולכן היא לא נכנסת לגיט.

עכשיו במחשב שלך:

```bash
cp app/config.example.js app/config.js
```

והדבק את הכתובת ב-`ENDPOINT`.

---

## 5 · בדיקה מקצה לקצה

**לפני השיעור, לא בשיעור.**

1. הרם שרת סטטי והיכנס ל-`app/login.html`
2. התחבר עם שם וקוד אמיתיים מהגיליון
3. כתוב קוד → הרצה → בדיקות
4. **כתוב לאלעד שאלה.** הוא אמור לענות תוך כמה שניות
5. **הגשה**
6. פתח את הגיליון — `submissions` ו-`chat` אמורים להתמלא
7. **סגור את הדפדפן, פתח מחשב אחר, התחבר שוב.** הקוד שלך חייב לחזור

> שלב 7 הוא הבדיקה היחידה שבאמת חשובה. **הוא זה שמוכיח שהמחשבים
> יכולים להתחלף** — וזו הסיבה שכל השרת הזה קיים.

---

## אחרי השיעור — הציונים

**הטסטים הנסתרים לא רצו על השרת ולא בדפדפן, בכוונה.** שרת שמריץ קוד
של תלמידים הוא בעיית אבטחה בפני עצמה, ולא פותרים אותה ביומיים.

הגש את ההגשות מהגיליון ל-`tools/run_week.py` אחרי השיעור. ‏`SPEC` §7
נשמר במלואו: **הטסטים קובעים, לא המודל** — רק שהם רצים אצלך.
